AudioControl

A native iPhone controller and ESP32 firmware project for subwoofer delay, crossover, deep-bass shaping, and repeatable acoustic measurement.

Support

For setup help, bug reports, or feature requests, open an issue in the AudioControl issue tracker.

Include the board revision, firmware revision, iPhone model, iOS version, and a concise description of what happened. Never attach App Store credentials, API keys, private keys, or recordings you do not intend to publish.

Documentation

The source repository contains hardware notes, firmware build instructions, the BLE protocol, and the Mac agent-audio command-line interface.
